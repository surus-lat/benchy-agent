Build your benchmark

Describe what you want to evaluate. Benchy Agent helps turn it into a precise program, scoring function, data definition, and AI-system configuration.

“Evaluate whether the assistant cites the right statute for a case summary.”

program

task: cite_statute input: case_summary output: statute_id + rationale

scoring

exact_match: statute_id rubric: rationale_quality weights: 0.7 / 0.3

data

source: course_corpus n_items: 240 constraints: 1 statute/item

ai-system

kind: agent adapter: http params: temperature 0.2

The agent and the authoring UI write the same four blocks — nothing is inferred behind your back.

Generate the exam

Generate synthetic benchmark data from your context, constrained and validated by the benchmark you defined.

240 items generated from your corpus 236 valid · 4 rejected
001 Case summary → expected statute 42-B valid
002 Case summary → expected statute 17-A valid
003 Two statutes in one item — violates constraint rejected

Every item is checked against the data definition before it enters the exam, so generation failures surface as rejections rather than silent noise in your results.
